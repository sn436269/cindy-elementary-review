# Cindy 學習基地｜明湖國小複習站

正式網址：[Cindy 國小複習站](https://sn436269.github.io/cindy-elementary-review/)。

明湖國小五年級上學期的家庭複習網站，採《明日方舟：終末地》同人主題，非遊戲或學校官方網站。五科共 41 個課次／小節、1,230 題，每個小節至少 30 題。支援「科目 → 大單元 → 小節」選題、每日任務、錯題解析、PNG 完成卡、點數存摺及家長兌換。

- 國語：8 個課次／統整活動，240 題。
- 數學：15 個小節／加強任務，450 題。
- 自然：1-1、1-2、1-3、2-1、2-2、2-3，各 30 題，共 180 題。
- 英語：6 個字詞／句型／閱讀小節，180 題。
- 社會：6 個主題小節，180 題。

自然 1-3 能源與植物分類含家長指定補充；各科小節編號為本站整理的練習編號，實際考試範圍以班級通知為準。原 600 題的 ID 與既有紀錄保留；儲存資料庫名稱不變。

靜態 HTML/CSS/JavaScript，可由 GitHub Pages 提供；登入同步使用選配的 Firebase Authentication 與 Cloud Firestore，首次須自行設定服務。未設定時只保存於目前瀏覽器。

請閱讀 [家長使用與雲端設定](SETUP.md)、[完整小節目錄](小節題庫目錄.txt)、[自然小節來源](sources-science-v2.md)、[數學小節來源](sources-math-v2.md)、[英語與社會來源](sources-sections-v2.md)。

視覺使用內建 ImageGen 製作，原始 PNG 與網頁用 WebP 保存在 `assets/`；[最終提示與製作說明](assets/主視覺製作說明.md)。
